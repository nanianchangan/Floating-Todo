# Floating-Todo

我做了一个提醒自己专注当下的 Mac 小工具

人的有限，让聚焦成为必然。

MIT（Most Important Tasks）效率方法提出：每天只聚焦 1～3 件最重要的事。但学习和工作中很容易出现重要事情被打断，被琐事驱逐。

Floating Todo 因此而生——一个始终置顶的「当前工作栈」，它记录手头正在处理的几件事。待办清单回答的是：“我还有什么要做？”Floating Todo 更关心的是：“我现在到底在做什么？”

重要的不是一天中完成更多事情，而是把手头真正重要的事情做完。
